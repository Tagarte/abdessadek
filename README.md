
# Portfolio — Abdessadek Tagarte

Portfolio personnel présentant mes compétences et projets en ingénierie logicielle, Backend, Cloud et DevOps.

## Stack technique

- HTML5 sémantique
- CSS3 : variables, Grid, Flexbox et glassmorphism
- JavaScript vanilla (sans framework ni dépendance)
- Interface bilingue : français et anglais
- Mode sombre et clair
- Déploiement avec GitHub Pages
